# PaperFix

PaperFix is a web app for academic writing assistance and technical document rewriting.

Official site: https://www.paperfixes.com

## Scope

PaperFix helps with sentence restructuring, expression cleanup, terminology preservation, length control, and manual review support. Outputs are writing aids only and should be reviewed by the author before use.

## Recommended use

- Process one paragraph at a time.
- Do not submit private, confidential, unpublished, or sensitive information.
- Review meaning, terminology, data, citations, and context before using any output.
